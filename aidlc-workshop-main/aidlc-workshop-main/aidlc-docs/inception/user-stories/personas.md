# 테이블오더 서비스 - 사용자 페르소나

---

## Persona 1: 고객 (Customer)

### 기본 정보
| 항목 | 내용 |
|------|------|
| **이름** | 김민수 (대표 페르소나) |
| **역할** | 매장 방문 고객 |
| **연령대** | 20~60대 (폭넓은 연령층) |
| **기술 수준** | 초급~중급 (스마트폰/태블릿 기본 사용 가능) |

### 특성
- 매장에 방문하여 테이블에 앉은 고객
- 태블릿을 통해 메뉴를 탐색하고 주문하는 사용자
- 별도 앱 설치나 회원가입 없이 즉시 사용
- 다양한 연령대와 기술 숙련도를 가진 사용자

### 목표
- 빠르고 간편하게 메뉴를 확인하고 주문하기
- 주문 상태를 실시간으로 확인하기
- 추가 주문을 쉽게 하기
- 현재까지의 주문 내역과 총 금액 확인하기

### 동기
- 직원을 기다리지 않고 즉시 주문하고 싶음
- 메뉴 사진과 설명을 보고 신중하게 선택하고 싶음
- 주문 실수를 줄이고 싶음 (직접 선택하므로)

### 불만 요소 (Pain Points)
- 복잡한 인터페이스나 작은 버튼
- 느린 응답 속도
- 주문이 제대로 들어갔는지 확인할 수 없는 상황
- 이전 손님의 주문 내역이 보이는 경우

## Persona 2: 매장 관리자 (Admin)

### 기본 정보
| 항목 | 내용 |
|------|------|
| **이름** | 박서연 (대표 페르소나) |
| **역할** | 매장 운영자 / 점주 |
| **연령대** | 30~50대 |
| **기술 수준** | 중급 (PC/태블릿 업무 사용 가능) |

### 특성
- 매장의 전반적인 운영을 담당하는 관리자
- 주문 접수, 메뉴 관리, 테이블 관리를 수행
- 바쁜 영업 시간 중에도 시스템을 사용해야 함
- 단일 매장을 운영하며 시스템 관리도 직접 수행

### 목표
- 들어오는 주문을 실시간으로 빠르게 확인하기
- 주문 상태를 효율적으로 관리하기
- 메뉴를 쉽게 등록/수정/삭제하기
- 테이블 회전율을 높이기 위해 이용 완료 처리를 빠르게 하기
- 과거 주문 내역을 확인하기

### 동기
- 인건비 절감 (주문 접수 인력 감소)
- 주문 누락 방지 (시스템 자동 기록)
- 운영 효율성 향상 (실시간 모니터링)
- 고객 만족도 향상 (빠른 주문 처리)

### 불만 요소 (Pain Points)
- 주문이 실시간으로 반영되지 않는 경우
- 복잡한 관리 화면
- 잘못된 주문을 수정/삭제하기 어려운 경우
- 테이블 이용 완료 처리가 번거로운 경우
