# 테이블오더 서비스 - 컴포넌트 정의

## 1. 프레젠테이션 레이어 (Presentation Layer)

### 1.1 CustomerUI
- **목적**: 고객이 테이블에서 메뉴를 탐색하고 주문하는 웹 인터페이스
- **책임**:
  - 테이블 자동 로그인 화면 / 초기 설정 화면
  - 카테고리별 메뉴 목록 표시 (카드 레이아웃)
  - 메뉴 상세 정보 표시
  - 장바구니 관리 UI (추가/삭제/수량 조절)
  - 주문 확정 및 결과 표시
  - 주문 내역 조회 화면
- **기술**: Next.js App Router, React Client Components, localStorage
- **경로**: `/customer/*`

### 1.2 AdminUI
- **목적**: 관리자가 매장을 운영하고 주문을 관리하는 웹 인터페이스
- **책임**:
  - 관리자 로그인 화면
  - 실시간 주문 모니터링 대시보드 (그리드 레이아웃)
  - 주문 상세 보기 및 상태 변경
  - 테이블 관리 (초기 설정, 이용 완료, 주문 삭제)
  - 과거 주문 내역 조회
  - 메뉴 CRUD 관리 화면
- **기술**: Next.js App Router, React Client Components, SSE EventSource
- **경로**: `/admin/*`

---

## 2. API 레이어 (API Layer)

### 2.1 AuthAPI
- **목적**: 인증 및 세션 관리 API
- **책임**:
  - 테이블 태블릿 로그인 (자동 로그인용 토큰 발급)
  - 관리자 로그인 (JWT 발급, 16시간 만료)
  - 토큰 검증 미들웨어
  - 로그인 시도 제한 (brute-force 방지)
- **경로**: `/api/auth/*`

### 2.2 MenuAPI
- **목적**: 메뉴 조회 및 관리 API
- **책임**:
  - 메뉴 목록 조회 (카테고리별, 공개)
  - 메뉴 상세 조회 (공개)
  - 메뉴 등록/수정/삭제 (관리자 전용)
  - 메뉴 노출 순서 변경 (관리자 전용)
  - 입력값 검증 (필수 필드, 가격 범위)
- **경로**: `/api/menu/*`

### 2.3 OrderAPI
- **목적**: 주문 생성 및 조회 API
- **책임**:
  - 주문 생성 (고객)
  - 현재 세션 주문 내역 조회 (고객)
  - 주문 상태 변경 (관리자)
  - 주문 삭제 (관리자)
  - SSE 실시간 주문 스트림 (관리자)
- **경로**: `/api/orders/*`

### 2.4 TableAPI
- **목적**: 테이블 관리 API
- **책임**:
  - 테이블 초기 설정 (관리자)
  - 테이블 이용 완료 처리 (관리자)
  - 과거 주문 내역 조회 (관리자)
  - 테이블 목록 조회 (관리자)
- **경로**: `/api/tables/*`

## 3. 서비스 레이어 (Service Layer)

### 3.1 AuthService
- **목적**: 인증 비즈니스 로직
- **책임**:
  - 비밀번호 해싱 및 검증 (bcrypt)
  - JWT 토큰 생성 및 검증
  - 로그인 시도 횟수 관리
  - 세션 만료 처리

### 3.2 MenuService
- **목적**: 메뉴 비즈니스 로직
- **책임**:
  - 메뉴 CRUD 오퍼레이션
  - 카테고리별 메뉴 조회
  - 메뉴 노출 순서 관리
  - 데이터 검증 (필수 필드, 가격 범위)

### 3.3 OrderService
- **목적**: 주문 비즈니스 로직
- **책임**:
  - 주문 생성 (메뉴 유효성 검증, 금액 계산)
  - 주문 상태 전이 (대기중 → 준비중 → 완료)
  - 주문 삭제 및 금액 재계산
  - SSE 이벤트 발행

### 3.4 TableService
- **목적**: 테이블 및 세션 비즈니스 로직
- **책임**:
  - 테이블 등록 및 설정
  - 테이블 세션 관리 (시작/종료)
  - 이용 완료 처리 (주문 이력 이동, 리셋)
  - 과거 주문 내역 조회

---

## 4. 데이터 액세스 레이어 (Data Access Layer)

### 4.1 Database (Prisma ORM)
- **목적**: SQLite 데이터베이스 접근
- **책임**:
  - Prisma 스키마 정의 및 마이그레이션
  - CRUD 오퍼레이션
  - 트랜잭션 관리
  - 시드 데이터 생성 (관리자 계정)

---

## 5. 공통 레이어 (Common/Shared)

### 5.1 Middleware
- **목적**: 요청 처리 파이프라인
- **책임**:
  - JWT 토큰 검증 미들웨어
  - 입력값 검증 (Zod 스키마)
  - 에러 핸들링
  - 보안 헤더 설정
  - Rate limiting
  - 구조화된 로깅

### 5.2 Types
- **목적**: TypeScript 타입 정의
- **책임**:
  - API 요청/응답 타입
  - 데이터 모델 타입
  - 공통 유틸리티 타입

### 5.3 SSEManager
- **목적**: Server-Sent Events 관리
- **책임**:
  - SSE 연결 관리
  - 이벤트 브로드캐스트
  - 연결 해제 처리
