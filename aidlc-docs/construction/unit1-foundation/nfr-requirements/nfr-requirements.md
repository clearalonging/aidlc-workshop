# Unit 1 (Foundation) - NFR 요구사항

---

## 1. 성능 요구사항

| ID | 요구사항 | 목표값 | 측정 방법 |
|----|---------|--------|----------|
| PERF-01 | 인증 API 응답 시간 | < 500ms (p95) | 로그 기반 측정 |
| PERF-02 | JWT 검증 시간 | < 10ms | 미들웨어 처리 시간 |
| PERF-03 | bcrypt 해싱 시간 | < 300ms (cost 12) | 허용 범위 내 |
| PERF-04 | SSE 이벤트 전달 지연 | < 2초 | 주문 생성 → SSE 수신 |
| PERF-05 | DB 쿼리 응답 시간 | < 100ms (p95) | Prisma 쿼리 로그 |

## 2. 보안 요구사항

| ID | 요구사항 | 구현 방법 |
|----|---------|----------|
| SEC-01 | 비밀번호 안전 저장 | bcrypt (cost 12) |
| SEC-02 | JWT 토큰 보안 | HS256, 환경 변수 Secret |
| SEC-03 | Brute-force 방지 | 5회 실패 시 15분 차단 |
| SEC-04 | HTTP 보안 헤더 | CSP, HSTS, X-Frame-Options 등 |
| SEC-05 | 입력값 검증 | Zod 스키마 검증 |
| SEC-06 | Rate Limiting | 로그인 10/분, 일반 100/분 |
| SEC-07 | 민감 정보 로깅 금지 | 비밀번호, 토큰 로그 제외 |
| SEC-08 | CORS 제한 | 허용 Origin 명시적 설정 |
| SEC-09 | SQL Injection 방지 | Prisma ORM (파라미터화 쿼리) |
| SEC-10 | 에러 정보 노출 방지 | 프로덕션 일반 메시지만 반환 |
